## 日志库 v1.0
1、日志封装成类，支持不同级别的日志，DEBUG、WARNING、ERROR。
2、调用日志写入的接口，支持多参数，函数内部生成一个对象放入队列，线程函数中将会处理这个对象产生的字符串信息和报警级别。
3、维护双缓冲区，两个缓冲区的大小一样，当其中一个缓冲区满的时候，与另外一个缓冲区交换，将缓冲区的内容全部写入日志文件中。
4、日志文件写入指定目录，文件名为InfoLog.0依次递增，日志文件最大1024KB，最多100个，多了就删除旧的文件。
5、系统正常退出时，比如向缓冲区所有的内容都写入文件中，再退出。
